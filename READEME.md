# IoT Platform

## Требования

- Docker Desktop
- (Опционально) GNU Make (`make`) — для удобных команд
- Git

## Структура проекта

- `infrastructure/` — docker-compose и конфиги инфраструктуры
- `configuration/` — конфиги Loki/Alloy и др. (если используется)
- `Makefile`
    - `up` - команда выполняющая поднятие контейнеров
    - `down` - команда для остановки контейнеров
    - `restart` - команда для перезапуска контейнеров
    - `build` - команда для поднятия контейнеров со сборкой сервисов
    - `logs` - команда для вывода логов контейнеров
    - `clean` - команда для полной очистки контейнеров
## Cтарт проекта

- `docker-compose`
    - выполните команду `cd infrastructure`
    - после этого можете выполнять любую команду для `docker-compose` (пример: `docker compose up -d`)


- `Makefile`
    - в командной строке прописываете `make` и команда которая вам нужна, со списком команд можно ознакомиться в пункте `Структура проекта`
