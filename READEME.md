# IoT Platform

Инфраструктура и сервисы проекта IoT Platform.

## Требования
- Docker Desktop
- (Опционально) GNU Make (`make`) — для удобных команд
- Git

## Структура проекта
- `infrastructure/` — docker-compose и конфиги инфраструктуры
- `configuration/` — конфиги Loki/Alloy и др. (если используется)
- `services/` — микросервисы (если есть)
